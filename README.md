# HospitalEmergencyRoom Excel Practice Project

An interactive data analytics project designed to analyze hospital emergency room operations, monitor patient flow, evaluate waiting times, and support data-driven healthcare decision-making.

# Tools Used

* Microsoft Excel

# Project Architecture

* HospitalEmergencyRoom_Data.csv — Source dataset.
* HospitalEmergencyRoom_Excel_File.xlsx — Excel workbook containing the dashboard and analysis.
* Project_Ppt.pptx — Project documentation and analytical workflow.
* HospitalEmergencyRoom_Dashboard_Picture.png — Dashboard preview.

## Key Performance Indicators 

* Monitor the total number of patients visiting the emergency room.
* Track average patient waiting time and satisfaction scores.
* Analyze admitted versus non-admitted patients.
* Understand patient demographics through age-group and gender analysis.
* Identify the departments receiving the highest number of referrals.
* Evaluate patient attendance timeliness to highlight potential service bottlenecks.

# Key Observations

Based on the displayed dashboard:

* Patient admissions: 231 admitted patients versus 233 non-admitted patients.
* Admission distribution: Approximately 49.78% admitted and 50.22% not admitted.
* Patient attendance status: 58% recorded as delayed and 42% as on time in the displayed selection.
* Department referrals: The dashboard shows the highest referral count under “None,” followed by General Practice and Orthopedics.
* Age distribution: The 10–19 age group has the highest displayed count, with 65 patients, followed by the 0–9 age group with 63 patients.
